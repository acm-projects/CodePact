<h1 align="center"> CodePact 🤝 </h1>
<h3 align="center"> "Scarcity says there's only one winner. Abundance knows that when your friends win, you win too." </h3>
<div align="center">  The tech recruiting cycle is an isolating grind. CodePact rejects this scarcity mindset, transforming the job hunt into a team sport. Our platform lets you form a squad with friends to conquer the job search together. You'll share curated Leetcode problem lists, build a collective job board with real-time alerts, and give feedback on resumes. With a live activity feed and friendly leaderboards, CodePact keeps your crew motivated and accountable. This isn't just another job board; it's a collaborative workspace designed to help your entire team land the offers you deserve. </div>


## MVP 🏆
- User Authentication & Profile
- Squads (Groups)
- Shared Problem Lists & Notes
- Squad Hub & Resource Sharing
- Real-Time Squad Feed
- Gamified Leaderboards

## Stretch Goals 🌟
- Flashcard Quiz Feature
- Spaced Repetition
- Shared Squad Goals
- Advanced Gamification
- AI-Generated Mock Interview Questions
- AI-Powered Resume Feedback

## GitHub Cheat Sheet ⚡️

General Use

| Command | Description |
| ------ | ------ |
| cd "CodePact" | Change directories over to our repository |
| git branch | Lists branches for you |
| git branch "branch name" | Makes new branch |
| git checkout "branch name" | Switch to branch |
| git checkout -b "branch name" | Same as 2 previous commands together |
| git add . | Finds all changed files |
| git commit -m "Testing123" | Commit with message |
| git push origin "branch" | Push to branch |
| git pull origin "branch" | Pull updates from a specific branch |
